# Local development

This is a static HTML, CSS and JavaScript site. It has no package dependencies or build step.

From /workspace/WOPEGEE-Site run:

    python3 -m http.server 8000 --bind 0.0.0.0

Open the site through your development environment's supported browser access. Deploy index.html, styles.css, script.js and assets/ together to any static host when ready. No deployment has been performed.

See CONTENT-SOURCES.md for source provenance and items to confirm before launch.
